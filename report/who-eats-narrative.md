# Who eats — 課題設定の経緯・本質・展望

> **班内共有用の「公式ストーリー」**  
> ミニ発表・中間レポート・最終レポートでは、本ドキュメントの表現を軸にする。  
> 地図・友達フィードは **手段** であり、**食生活の偏りを防ぐ・続ける** ことが本題。

---

## 1. なぜこのアプリを選んだか（経緯）

### 1.1 出発点：一人暮らしと食生活

大学生が **急に一人暮らしを始める** と、次のような困りごとが重なる。

- **食事の管理**が立てられない（いつ何を食べたか把握できない）
- **偏食**がちになる（同じもの・コンビニ頼み・外食の偏り）
- 自炊のモチベーションやスキルが追いつかない

班では、この問題を **自分たちや周囲の実体験** として共有した。

### 1.2 最初の案：自炊管理アプリ

最初は **自炊の記録・管理に特化したアプリ** を想定した。

- カロリー入力、献立表、買い物リストなど
- 「食生活を整える」という目的には直結する

しかし検討の結果、次の課題が明らかになった。

| 課題 | 説明 |
|------|------|
| **継続性** | 管理・入力が中心のアプリは、負担が大きく **続かない** |
| **動機づけ** | 一人で記録するだけでは、習慣化しづらい |
| **利用頻度** | 週1回の入力では生活改善につながりにくい |

### 1.3 行き着いた形：友達と共有する SNS 型の食事投稿

**持続しやすい** ことを最優先に設計を見直した。

- **みんなが日々投稿しやすい** フォーマット（写真＋短いコメント）
- **友達との共有** により、見られる・真似できる・会話が生まれる
- 自炊も外食も **同じ流れで記録** できる（製品仕様の「自炊投稿」）

つまり Who eats は、

> **「食生活・偏食の課題を、継続可能な SNS 体験で支える」**  
> ために、友達との食事共有＋地図という形を選んだ。

グルメマップは **外食の偏りを減らし、信頼できる人の選択を助ける手段** であり、目的そのものではない。

---

## 2. 本アプリが扱う課題（常に強調する核心）

以下をレポート・発表の **主題** として一貫させる。

1. **自炊の支援** — 何を食べたか可視化し、自炊の継続を促す  
2. **偏食・食生活の偏りの防止** — 外食のみ・同ジャンルばかりなどを、記録と友人の目で意識化する  
3. **一人暮らし大学生の食の不安** — 管理のしやすさと、続けられる仕組み

### 2.1 PBL「3条件」への当てはめ

| 条件 | 内容 |
|------|------|
| **切実性・当事者性** | 一人暮らし開始後の食生活の乱れ・偏食は、班員の実体験・周囲の話として具体的 |
| **普遍性・社会性** | 進学・就職・単身赴任など「突然ひとりで食べる」場面は広い；若年層の外食・コンビニ依存も社会課題として語れる |
| **情報技術による解決可能性** | 投稿・タイムライン・（将来）画像解析・食事回数の可視化で改善が期待できる |

### 2.2 手段としての機能（サブメッセージ）

| 機能 | 課題との関係 |
|------|----------------|
| 食事投稿（自炊／外食） | 食べたものの記録 → 偏りの自覚 |
| 友達フィード | 継続の動機・ロールモデル |
| 地図・店舗 | 外食時の選択支援（偏食・行き過ぎた店の回避） |
| 記録タブ | 食生活の振り返り（課題3で拡張予定） |

**キャッチ（対外）**: 「知らない星5より、友達の一枚」  
**本質（対内・レポート）**: 「続く食の記録で、偏らない食生活を」

## 3. 既存サービスとの位置づけ

| 種類 | 例 | 限界 |
|------|-----|------|
| カロリー・献立管理 | あすけん等 | 入力負荷が高く継続しにくい |
| グルメ・地図 | Google、食べログ | **店**中心で **食生活全体・偏食** は見えない |
| 一般 SNS | Instagram | 食事は断片で、構造化・振り返りに弱い |

Who eats の差別化: **食生活・偏食** を主題にしつつ、**友達 SNS＋地図** で **続く** 設計。

## 4. 今後の展望

### 4.1 技術的展望（課題3以降・卒業後も含む）

| 方向 | 内容 |
|------|------|
| **AI 画像解析** | 投稿写真から食品カテゴリを推定し、**食事の偏り**（野菜不足・炭水化物過多など）を分析・可視化 |
| **食事回数の管理** | **1日1・2・3食** が取れているかの記録・リマインド・ダッシュボード化 |
| **栄養アドバイス** | 分析結果に基づく改善提案（ルールベース → 将来 ML） |

### 4.2 事業・スポンサー計画（展望）

持続可能な運営と専門性の担保のため、**栄養士・関連団体のスポンサー** を想定する。

| 項目 | 概要 |
|------|------|
| **スポンサー候補** | 管理栄養士・栄養士会、大学保健センター、食品・健康関連企業 |
| **提供価値（スポンサー向け）** | 健康意識の高い大学生へのリーチ、偏食改善キャンペーン、専門監修の明示 |
| **アプリ側の価値** | 監修付きコンテンツ、栄養相談窓口への導線、偏り分析レポートのブランド信頼 |
| **収益モデル（案）** | スポンサーシップ、大学連携パッケージ、将来はプレミアム分析機能（無償枠は維持） |

※ 課題3のプロトタイプ範囲では **未実装**。中間・最終レポートの「展望」「事業計画」節に記載する。
