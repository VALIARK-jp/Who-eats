| レイヤ | 技術 | 主なパス |
|--------|------|----------|

## 3. 作業手順（実装時に踏んだ流れ）

1. **DB スキーマ**: `supabase/migrations/` でテーブル・RLS・RPC を順次適用（`supabase db push`）。
2. **エンティティ**: `app_entities.dart` に FeedPost、UserProfile 等を定義。
3. **データソース**: `SupabaseSocialDataSource` に REST/RPC 呼び出しを集約。
4. **ユースケース**: リポジトリ経由で Controller から呼び出し。
5. **UI**: `app_shell_page.dart` を中心にタブ・フィード・マップを統合。
6. **検証**: `dart analyze`、実機／エミュレータでのデモ経路確認。

## 5. 動作結果（デモで示すポイント）

- ログイン後、ホームに自分・友達の投稿が表示される
- スコープチップで「友達／近い／すべて」を切替（設定の初期値と連動）
- 投稿にいいね・コメント（2件以上は1件＋「他N件」）
- 店舗詳細からマップ上の該当店へ遷移
- プロフィールから `@user_code` 検索・フォロー

**スクリーンショット**: 最終レポート用に `report/assets/` を班で作成し、図として挿入すること（未作成）。
