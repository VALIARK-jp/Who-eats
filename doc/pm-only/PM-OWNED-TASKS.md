# PMが自分で持つタスク（固定）

## 1. 認証基盤

- Auth導入（登録/ログイン/ログアウト）
- セッション管理
- 認証ガード（未ログイン時遷移制御）

## 2. データ基盤

- DBスキーマ確定とmigration管理
- RLSポリシー管理
- 監査・ログ方針管理

## 3. API/境界設計

- 5コアフロー仕様の固定
- **配布前**: 投稿最小・タイムライン・店詳細・マップピンの **4フローはPMが縦に通す**（実装チェックリストは [PM-PRE-DISTRIBUTION-IMPLEMENTATION.md](./PM-PRE-DISTRIBUTION-IMPLEMENTATION.md)）。フォロー／解除の実装はメンバーレーンに残してよい。
- **配布物**: メンバーには [phase1/assignments/README.md](../phase1/assignments/README.md) から個票を指定する。
- API契約更新と配布
- 仕様変更時の承認フロー運用

## 4. チーム運用

- タスク配布順序の決定
- PRレビュー基準統一
- フェーズ進行管理（5/22, 6/5, 7月下旬）

## 5. リスク管理

- Apple Team移行に伴うiOSリリース準備管理
- キー管理・環境変数管理
- リリース前の凍結判断
