## スプリントの切り方（合意案）

| **スプリント1** | **リリース可能な MVP** まで実装・実機確認・Store 準備 | PM（あなた）が DB/API/実機必須フローを通す。メンバーは **アイコン・UI・テーマ・ドキュメント・手動テスト** |

## DB・構想はあるが UI/接続がモック or 未完了（スプリント1で詰める候補）

### A. マイグレーション済み・Flutter 未接続（優先度高）

| 機能 | DB / RPC | アプリ現状 | スプリント1 |
|------|----------|------------|-------------|
| 連続記録更新 | `bump_user_streak_on_post()`（`003`） | 投稿成功後に **RPC 未呼び出し** | **接続する** |
| タイムライン scope | `get_near_feed_user_ids()`（`004`） | フィードは **全件取得のみ**（友達/近い人/全体 UI なし） | **UI + 取得条件** またはスプリント2へ明記除外 |
| 同行者・同じごはん | `whoeats_post_companions` + `meal_group_id`（`005`） | 投稿は **`withWho` 自由テキストのみ**、DB 未保存 | **スプリント2推奨**（範囲大） |

### B. テーブルはあるが操作 UI なし（仕様上 MVP に入れるならスプリント1）

| 機能 | DB | アプリ現状 | スプリント1 |
|------|-----|------------|-------------|
| いいねトグル | `whoeats_post_reactions` | **件数表示のみ**、タップ不可 | **実装する**（P1-04） |
| コメント | `whoeats_post_comments` | **件数表示のみ**、一覧/投稿 UI なし | **実装する**（P1-03） |
| 投稿削除 | `deleted_at` 想定 | UI なし | 最低限・自分投稿のみ |
| ブロック | RLS / `is_blocked` | UI なし | スプリント2可 |
| 投稿評価（1–5） | `whoeats_posts.rating` 列利用可 | 投稿フォームに **評価入力なし**、フィードは **★4.5 固定** | 入れるなら **保存 + 表示** |
| 通知インボックス | `list_inbox_notifications` | ベル → **一覧はある**、未読・遷移は薄い | **最低限の遷移** またはスプリント2 |

### C. UI がモックのまま（DB 不要 or 別テーブル）

| 機能 | 現状 | スプリント1 |
|------|------|-------------|
| 記録タブ・日別パネル | 店名・回数・友達が **固定配列**（`calendar_record_view.dart`） | **当月投稿の実データ**に差し替え |
| 記録・栄養サマリ | `caloriesAvg` / `proteinAvg` = 0、AI 文案のみ | **「準備中」表示で統一**（スプリント2: P1-32） |
| からむで探す・おすすめタグ | タグ **const 固定**、タップ未接続 | スプリント2（興味タグ DB なし） |
| フィードカードの評価・投稿時間 | `FoodPostCard` 内 **rating 4.5 固定** | 実データ or 非表示に統一 |
| 他ユーザープロフィール遷移 | 「未実装（MVP）」SnackBar | スプリント2 |
| 利用規約リンク | 空 URL 時「掲載準備中」 | 文案・URL 確定（リリース必須なら D4） |
