# TASK-P1-03: コメント機能（投稿に返信する）

> **親ドキュメント**: [TASKS.md](../TASKS.md) の「TASK-P1-03」  
> **ブランチ名の例**: `feature/p1-03-comments`

---

## 目的

- 友達の投稿の下で、**短いコメントを読む・書く・消す** ができるようにする。
- 空コメントや長すぎるコメントで **おかしな表示やクラッシュ** が出ないようにする。

---

## 説明

### アプリ上でどう見えるか

- 投稿の詳細画面や一覧のカードを開くと、**コメント一覧**が下に並ぶ。
- **入力欄**と「送信」、自分のコメントには「削除」があるイメージ。

### 用語ミニ辞典（このタスクだけ）

| 用語 | 意味 |
|------|------|
| **一覧** | これまでに付いたコメントを上から順に並べたもの。 |
| **バリデーション** | 「空は送れない」「文字数は○文字まで」などのルールチェック。 |

### 前提（先に終わっていること）

- 投稿が1件は画面に表示され、**どの投稿か**が分かる状態（投稿IDが取れる）。
- コメント用のAPIの形が `doc` に書かれている（無い場合はPMに確認してから着手）。

---

## 方法

### 非エンジニアの方へ（進め方）

1. **何文字まで**書けるか、**空送信**を許すかを仕様書またはPMに確認し、メモに残す。
2. 画面の **エラー時の日本語**（例:「送信できませんでした。もう一度お試しください」）を決める。
3. 完成後、実機で「**他人の投稿に1件、自分の投稿に1件**」コメントしてみて、一覧と削除が自然か確認する。

### エンジニアの方へ（実装の進め方）

1. 投稿詳細（または該当ウィジェット）の下に **`ListView.builder`** でコメント行を並べる。各行は **`ListTile`** の **`title`**（本文）と **`subtitle`**（日付・名前）が使いやすい。
2. 入力は **`TextField`**。空送信を禁止するなら **`controller`** の文字列を trim して長さ0ならボタン無効、または **`maxLength`** で上限を付ける。
3. 送信ボタンは **`IconButton(icon: Icon(Icons.send))`** など。送信中は **`CircularProgressIndicator`** を **`SizedBox` で小さく** 隣に置くと分かりやすい。
4. 削除は **`IconButton`** + 確認ダイアログ **`AlertDialog`** の **`actions`** に **`TextButton(onPressed: ...)`** を並べる定番でよい。
5. APIは「一覧取得」「作成」「削除」の3本を想定。失敗時は **`SnackBar`** で **`content: Text('...')`** を表示。

### 使うとよいウィジェット・プロパティの例

| やりたいこと | ウィジェット例 | プロパティの例 |
|--------------|----------------|----------------|
| 長文入力 | `TextField` | **`maxLines`**: 3〜5 / **`maxLength`**: 上限 |
| キーボードを閉じる | `TextField` | **`textInputAction: TextInputAction.done`**（画面構成による） |
| リストが空 | 画面構成 | **`ListView` の代わりに `Center(child: Text('まだコメントがありません'))`** など |

---

## 確認

- [ ] コメントが **一覧に表示**される。
- [ ] **空のまま送れない**（または仕様どおり送れるならその理由がPRに書いてある）。
- [ ] **自分のコメントだけ削除**できる（他人の削除ボタンが出ない等）。
- [ ] 通信エラーで **アプリが落ちない**。
- [ ] スクショが PR に Before / After で付いている。

---

## タスク

1. API（一覧・作成・削除）のパスとJSONを `doc` またはコメントで確認する。
2. 一覧UIを実装する（ローディング・0件も含む）。
3. 入力欄と送信を実装する（バリデーション付き）。
4. 削除と権限（本人のみ）を実装する。
5. 仕様と違う点があれば PR 本文に書く。
6. `flutter analyze` を通し、スクショを添付して PR を出す。
