# TASK-P1-04: リアクション（いいね）機能

> **親ドキュメント**: [TASKS.md](../TASKS.md) の「TASK-P1-04」  
> **ブランチ名の例**: `feature/p1-04-reactions`

---

## 目的

- 投稿に **ハート（いいね）を付けたり外したり** でき、件数が分かるようにする。
- 通信に失敗したとき、**数字だけズレて見える**状態を避ける（戻す・再取得するなど）。

---

## 説明

### アプリ上でどう見えるか

- 投稿カードに **ハートアイコン** と **数字**（いいねの数）。
- タップするたびに **付く／外れる**（仕様がトグルなら）。

### 用語ミニ辞典（このタスクだけ）

| 用語 | 意味 |
|------|------|
| **トグル** | オンとオフを交互に切り替える動き。 |
| **ロールバック** | 失敗したら、画面の数字を **元に戻す** こと。 |

### 前提（先に終わっていること）

- 投稿が表示されていること。
- リアクションAPI（付与・解除・件数）の仕様が `doc` か PM から共有されていること。

---

## 方法

### 非エンジニアの方へ（進め方）

1. **いいねの数**は「自分が付けた分も含む総数」でよいか、PMに確認。
2. **連打**したときの期待動作（連打しても壊れない）を確認する。
3. オフライン時の **一言メッセージ**（例:「接続を確認してください」）を決めると実装が早い。

### エンジニアの方へ（実装の進め方）

1. 表示は **`IconButton`** または **`InkWell`** の **`child: Icon(...)`**。塗りつぶしハートは **`Icons.favorite`**、未は **`Icons.favorite_border`**。
2. 件数は **`Text('$count')`** を横に並べる。レイアウトは **`Row`** の **`mainAxisSize: MainAxisSize.min`** でコンパクトに。
3. 楽観更新（先にUIを変えてからAPI）をする場合: 失敗時に **元の `count` とアイコン状態に戻す**。楽観しない場合: **API成功後だけ** UI を更新。
4. 送信中は **`onPressed` を null** にするか、**ローディング**を出して二重送信を防ぐ。

### 使うとよいウィジェット・プロパティの例

| やりたいこと | ウィジェット例 | プロパティの例 |
|--------------|----------------|----------------|
| タップ領域 | `IconButton` | **`iconSize`**, **`tooltip`**（長押しヒント） |
| 色 | `Icon` | **`color`**: 付与時は赤などブランドに合わせる |

---

## 確認

- [ ] タップで **付与・解除**が動く（仕様どおり）。
- [ ] **数がマイナスにならない**。
- [ ] 通信失敗時に **数字が嘘のまま残り続けない**（戻す・再取得のどちらか）。
- [ ] スクショ Before / After が PR についてる。

---

## タスク

1. API仕様を読む（エンドポイント・リクエスト・レスポンス）。
2. UI（アイコン＋件数）を置く。
3. トグル操作をAPIに結線する。
4. 失敗時の挙動（ロールバック or 再取得）を実装する。
5. 境界（未ログイン・自分の投稿など）をPMとすり合わせる。
6. `flutter analyze` と PR 提出。
