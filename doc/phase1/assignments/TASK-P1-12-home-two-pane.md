# TASK-P1-12: ホームの「投稿ビュー」と「マップ」を切り替えたとき、位置を覚えておく

> **親ドキュメント**: [TASKS.md](../TASKS.md) の「TASK-P1-12」  
> **ブランチ名の例**: `feature/p1-12-home-two-pane`

---

## 目的

- マップと投稿（リストなど）を行き来しても、**さっき見ていたスクロール位置や地図の表示**が極端にリセットされないようにする。
- 指でスワイプする・タブを押す、**両方の操作**で自然に切り替わる。

---

## 説明

### アプリ上でどう見えるか

- ホームで **マップ⇔投稿** を何度か切り替えても、リストのスクロールが先頭に飛びすぎない、地図の中心が毎回東京に戻らない、など。

### 用語ミニ辞典（このタスクだけ）

| 用語 | 意味 |
|------|------|
| **2ペイン** | 1つのホームの中で、主に2つの大きな見せ方を切り替えること。 |
| **状態保持** | 画面を一度隠しても、**内部の変数**に位置情報を覚えておくこと。 |

### 前提（先に終わっていること）

- ホームの土台となる画面がある（例: `app_shell_page.dart`）。**他の人と同じファイルを同時に大きく編集しない**ようPMに相談。

---

## 方法

### 非エンジニアの方へ（進め方）

1. 「**どこまで覚えるべきか**」を決める（例: リストのスクロールは覚える／地図のズームは覚える、等）。PMと合意書に残す。
2. 受け入れテストの **動画撮影手順**（タップ何回、どこを見るか）を書く。
3. **投稿まわりのPR** と同週に触る場合は、**順番**をPMに決めてもらう。

### エンジニアの方へ（実装の進め方）

1. リストは **`PageStorageKey<String>('home_feed')`** を **`ListView`** の **`key`** に渡すと、**スクロールオフセット**が親が **`PageStorage`** を持っていれば保持されやすい。
2. タブ切替で **ウィジェットを `dispose` しない** 構造（**`IndexedStack`** で子を重ねて **`index` だけ変える**）だと状態が残りやすい。**トレードオフ**: メモリ使用量が増えるのでPMと要相談。
3. 地図は **コントローラ**（例: GoogleMap の `controller`）の **カメラ位置**を **`State`** にキャッシュし、再表示時に **`animateCamera`** で復元。
4. スワイプは **`PageView`** の **`onPageChanged`** でタブインデックスと同期。

### 使うとよいウィジェット・プロパティの例

| やりたいこと | ウィジェット例 | プロパティの例 |
|--------------|----------------|----------------|
| 子を生かしたまま隠す | `IndexedStack` | **`index`**: 表示する子の番号 |
| スクロール保持 | `ListView` | **`key: PageStorageKey(...)`**（親に `PageStorage` が必要） |
