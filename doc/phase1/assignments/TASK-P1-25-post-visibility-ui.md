# TASK-P1-25: 投稿の「誰に見せるか」（公開範囲）のUIを分かりやすくする

> **親ドキュメント**: [TASKS.md](../TASKS.md) の「投稿（PM最小のあと）」  
> **ブランチ名の例**: `feature/p1-25-post-visibility`

---

## 目的

- `public`（全体）／`friends`（友だち）／`private`（自分）の **意味が誤解なく伝わる**。
- 初めての人が **安全側**に寄りやすい配置・初期値になる（PM方針に従う）。

---

## 説明

### アプリ上でどう見えるか

- 投稿画面のどこかに **3択のコントロール**と、それぞれの **短い説明文**（1行ずつ）。
- 投稿後、一覧で **公開範囲のバッジ**が付くかどうかは仕様次第（付くならこのタスクまたは別）。**外食／自炊の種別バッジ**は [P1-27](./TASK-P1-27-post-type-badges.md)。

### 用語ミニ辞典（このタスクだけ）

| 用語 | 意味 |
|------|------|
| **`SegmentedButton`** | 数個の選択肢を **横並びのブロック**で選ばせる部品。公開範囲に向きがち。 |
| **`RadioListTile`** | ラジオボタン付きの1行。説明文を **`subtitle`** に書ける。 |

### 前提（先に終わっていること）

- APIに **`visibility`（または同等）** を送れる（PM最小）。
- 仕様書で **3語の定義**が文章化されている。

---

## 方法

### 非エンジニアの方へ（進め方）

1. 各選択肢について **高校生に説明するつもりで1文**ずつ書く（PMが採用）。
2. **デフォルト**はどれにするか（多くは `friends` 寄り）をPMに決めてもらう。
3. 誤って `public` を選んだ人向けに **注意文**を付けるかどうかを検討。

### エンジニアの方へ（実装の進め方）

1. **`SegmentedButton<String>`** の例:  
   **`segments: [ButtonSegment(value: 'friends', label: Text('友だち')), ...]`**  
   **`selected: <String>{current}`**, **`onSelectionChanged: (s) => setState(() => current = s.first)`**  
   （APIの値と **必ず同じ文字列** にする。）
2. 説明文は **`Column`** の下に **`Text(style: Theme.of(context).textTheme.bodySmall)`** で3行。
3. 初期値は **`State` の初期化**または **`initState` でユーザーのデフォルト設定を読み込み**。

### 使うとよいウィジェット・プロパティの例

| やりたいこと | ウィジェット | プロパティ（意味） |
|--------------|--------------|---------------------|
| 3択 | `SegmentedButton` | **`segments`**, **`selected`**, **`onSelectionChanged`** |
| ラジオ | `RadioListTile` | **`value`**, **`groupValue`**, **`onChanged`** |
| 補足 | `Text` | **`style`** で弱い色の本文 |
