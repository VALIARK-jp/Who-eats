# TASK-P1-07: プロフィールの表示名・Bio などを編集する

> **親ドキュメント**: [TASKS.md](../TASKS.md) の「TASK-P1-07」  
> **ブランチ名の例**: `feature/p1-07-profile-edit`

---

## 目的

- 自分の **表示名・自己紹介（Bio）・デフォルトの公開範囲** をアプリから変更できるようにする。
- 保存に成功したか失敗したかが **ユーザーに分かる**ようにする。

---

## 説明

### アプリ上でどう見えるか

- プロフィールの「編集」から **フォーム画面**。
- 「保存」ボタンがあり、成功すると **トーストやダイアログ**、または前の画面に戻る。

### 用語ミニ辞典（このタスクだけ）

| 用語 | 意味 |
|------|------|
| **デフォルト公開範囲** | 新しい投稿を作るとき最初に選ばれている「誰に見せるか」の初期値。 |
| **Bio** | 自己紹介文。任意のことが多い。 |

### 前提（先に終わっていること）

- 初回プロフィール（`P1-11`）または同等で **`users` に自分の行**がある。
- 更新APIのフィールド名が分かっている（PMまたは `doc`）。

---

## 方法

### 非エンジニアの方へ（進め方）

1. 各項目の **最大文字数** と **必須か任意か** を仕様書から抜き出し、エンジニアに渡す。
2. 保存成功時の **一言**（「保存しました」）と、失敗時の **一言** を決める。
3. **user_code** をここで変えられるかどうかは仕様によるので、**PMに必ず確認**（多くの場合は別タスクまたは不可）。

### エンジニアの方へ（実装の進め方）

1. フォームは **`SingleChildScrollView`** の中に **`Column`** で **`TextField` / `TextFormField`** を縦に並べるとキーボードで隠れにくい。
2. **`TextFormField`** を使うなら **`validator: (v) => v == null || v.isEmpty ? '...' : null`** のようにルールを書ける。
3. 公開範囲は **`DropdownButtonFormField`** の **`items`** と **`onChanged`**、または **`SegmentedButton`**。
4. 保存は **`FilledButton(onPressed: () async { ... })`**。送信中は **`onPressed: null`** と **`CircularProgressIndicator`**。
5. 成功後は **`Navigator.pop`** または **`SnackBar`**。

### 使うとよいウィジェット・プロパティの例

| やりたいこと | ウィジェット例 | プロパティの例 |
|--------------|----------------|----------------|
| 複数行のBio | `TextField` | **`maxLines: 5`**, **`maxLength: 160`**（数値は仕様に合わせる） |
| ラベル付き入力 | `TextFormField` | **`decoration: InputDecoration(labelText: '表示名')`** |

## 確認

- [ ] 変更した内容が **アプリを開き直しても残っている**。
- [ ] 空欄・上限超えで **仕様どおりブロックまたは警告**がある。
- [ ] 失敗時にユーザーが **次に何をすればよいか**分かる。
- [ ] PR にスクショ。
