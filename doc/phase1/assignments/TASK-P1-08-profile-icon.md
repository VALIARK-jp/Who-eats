# TASK-P1-08: プロフィールのアイコン（顔写真）を変える

> **親ドキュメント**: [TASKS.md](../TASKS.md) の「TASK-P1-08」  
> **ブランチ名の例**: `feature/p1-08-profile-icon`

---

## 目的

- ギャラリーまたはカメラから **画像を選び、プレビューしてから確定** できる。
- 更新後、**タイムラインやプロフィール** に新しいアイコンが反映される。

---

## 説明

### アプリ上でどう見えるか

- 「アイコンを変更」→ **四角い枠にプレビュー**→「この写真にする」→ 少し待つ → 完了。

### 用語ミニ辞典（このタスクだけ）

| 用語 | 意味 |
|------|------|
| **Storage** | 画像ファイルそのものを置く場所（Supabase Storage 等）。DBには **場所を指す文字列** を保存することが多い。 |
| **プレビュー** | 確定前に、選んだ写真がどう見えるか見せる画面。 |

### 前提（先に終わっていること）

- アップロード先・APIの流れがPMから共有されている（**URL・最大サイズ・向き**）。
- 権限（写真へのアクセス）の方針が決まっている。

---

## 方法

### 非エンジニアの方へ（進め方）

1. **正方形に切り抜くか**、そのまま **丸でマスクするか** をデザインまたはPMに確認。
2. アップロード中の **文言**（「送信中…」）を決める。
3. 失敗時（ファイルが大きすぎる等）の **日本語メッセージ** を1パターン用意する。

### エンジニアの方へ（実装の進め方）

1. 画像選択は **`ImagePicker`** 等で `XFile` を取得 → **`Image.file(File(path))`** でプレビュー。 **`fit: BoxFit.cover`** を **`ClipOval`** や **`CircleAvatar`** と組み合わせると丸アイコンにしやすい。
2. **`CircleAvatar`** には **`backgroundImage: FileImage(...)`** または **`NetworkImage(url)`**。
3. アップロード中は **`Stack`** + **`CircularProgressIndicator`** などで上に重ねる。
4. 更新API成功後、**キャッシュされた古い画像URL** を更新する（ **`key: ValueKey(url)`** でウィジェットを振り直す等）。

### 使うとよいウィジェット・プロパティの例

| やりたいこと | ウィジェット例 | プロパティの例 |
|--------------|----------------|----------------|
| 丸いアイコン | `CircleAvatar` | **`radius`**, **`backgroundImage`** |
| 角丸プレビュー | `ClipRRect` | **`borderRadius`**, **`child: Image.file`** |

---

## 確認

- [ ] 選んだ画像が **確定前に確認**できる。
- [ ] 完了後、**他画面でも新アイコン**が見える（更新が必要な画面をリスト化して確認）。
- [ ] 大きい画像・権限拒否で **落ちない**。
- [ ] PR にスクショ。
