# TASK-P1-27: 投稿に「外食／自炊」バッジ（種別ラベル）を付ける

> **親ドキュメント**: [whoeats-screen-spec-v1.md](../../whoeats-screen-spec-v1.md) のタイムライン・投稿カードの見せ方（写真主役のうえで種別が分かること）／[whoeats-product-spec-v1.md](../../whoeats-product-spec-v1.md)（投稿種別・自炊の視認性）  
> **ブランチ名の例**: `feature/p1-27-post-type-badges`

---

## 目的

- タイムラインや投稿詳細などで、**ひと目で外食か自炊か**分かるようにする（誤解なく店を選びに行く／行かない判断ができる）。
- **アイコン・色・短いラベル**で軽く示し、写真主役のトーン（画面仕様 **3. UIトーン**）を崩さない。

---

## 説明

### アプリ上でどう見えるか

- 各投稿カードの **隅**や **ユーザー名の近く**に、小さな **`Chip`** または **`Container` + 角丸 + 短いテキスト**（例:「外食」「自炊」）。
- 自炊は **暖色・アクセント**などトーンに合わせた色でもよいが、**文字が読めるコントラスト**を保つ（NG方針: 灰色で見えない）。

### 用語ミニ辞典（このタスクだけ）

| 用語 | 意味 |
|------|------|
| **`Chip`** | 短いラベルを **カプセル型**で表示する部品。種別表示に向く。 |
| **`post_type`** | APIやモデル上 `restaurant` / `home`。UIはこれを見て出し分ける。 |

### 前提（先に終わっていること）

- 一覧API（タイムライン等）のレスポンスに **`post_type`（または同等）** が含まれる、またはフロントで判定できる。
- 表示対象のウィジェット（投稿カード）が **1か所以上**存在する。

---

## 方法

### 非エンジニアの方へ（進め方）

1. **ラベル文言**を確定する（「外食」「おうち」「自炊」から2語に絞る等）。**アクセシビリティ**用に **読み上げラベル**も同じ文言にするかPMに確認。
2. **どの画面に必須か** を表にする（例: タイムライン必須、店ボトムシートは任意）。
3. **色の意味**（自炊=ポジティブ）をトーンと矛盾しないか、UIトーン章と突き合わせる。

### エンジニアの方へ（実装の進め方）

1. 投稿カードの `build` 内で **`post.postType == PostType.home`** のように分岐し、**`Chip`** を出す。  
   - **`Chip(label: Text('自炊'), visualDensity: VisualDensity.compact)`** のように **`visualDensity`** で小さくする。  
   - または **`Badge`** を **`Stack` + `Positioned`** でカード角に重ねる。
2. **`Theme.of(context).colorScheme`** の **`primaryContainer` / `onPrimaryContainer`** を使うとダーク基調と整合しやすい。
3. 詳細画面・プロフィールのグリッドでも **同じ部品**（共通 `Widget` 関数でも可）に寄せるとブレが減る。Phase1は **共通化の義務は薄い**のでコピーでも可（`TASKS.md` のコンポーネント方針に従う）。

### 使うとよいウィジェット・プロパティの例

| やりたいこと | ウィジェット例 | プロパティの例 |
|--------------|----------------|----------------|
| 小さなラベル | `Chip` | **`label`**, **`visualDensity`**, **`materialTapTargetSize`** |
| アウトライン | `Chip` | **`variant: ChipVariant.outlined`**（Flutter バージョンによる。無ければ `side: BorderSide(...)`） |
| 角丸ラベル | `Container` | **`decoration: BoxDecoration(borderRadius: BorderRadius.circular(8), color: ...)`** |
