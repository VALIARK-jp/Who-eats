# フィード公開範囲・タブ表示 QA 手順書

Who eats の「公開設定」と「ホームフィードのタブ切り替え」が正しく動くかを確認するためのドキュメントです。

---

## 1. このタスクのゴール

担当者が確認すべきことは **2つ** です。

### ゴール A: 設定画面 → DB が更新される

**プロフィール編集** で「投稿のデフォルト公開範囲」を変更し保存したとき、`whoeats_users.default_visibility` が意図どおり書き換わること。

| UI ラベル | DB の値 |
|-----------|---------|
| 友達 | `friends` |
| 友達の友達 | `near` |
| 公開 | `public` |

設定画面で変更できるのはこの **デフォルト公開範囲** のみです。ホーム上部のタブ（友達 / 友達の友達 / 全体）はその場での閲覧切り替え用で、設定には含まれません。

### ゴール B: フィードタブ → 関係と公開設定に応じた人が出る

ホーム上部の **友達 / 友達の友達 / 全体** タブを切り替えたとき、下記の **想定挙動** どおりに投稿が表示されること。

---

## 2. 用語

| 用語 | 意味 |
|------|------|
| **公開設定** | 投稿（およびプロフィールのデフォルト）の公開範囲。`friends` / `near` / `public` の 3 段階。 |
| **友達** | 自分と **相互フォロー** の関係にあるユーザー。 |
| **友達の友達** | 自分とは相互フォローではないが、自分の友達がフォローしているユーザー（2ホップ）。 |
| **それ以外** | 上記のどちらでもないユーザー。 |

### 公開設定の 3 段階

| UI | DB 値 | 意味 |
|----|-------|------|
| 友達 | `friends` | 友達タブから見える |
| 友達の友達 | `near` | 友達の友達タブから見える |
| 公開 | `public` | 全体タブから見える |

---

## 3. 想定挙動

### 3.1 大原則

> **自分の友達は、公開設定に関係なく、どのタブにも表示されうる。**

### 3.2 タブごとの表示ルール

| タブ | 表示される投稿 |
|------|--------------|
| **友達** | **友達** の投稿（公開設定は問わない）＋ **自分** |
| **友達の友達** | **友達** の投稿 ＋ 公開設定が **友達の友達** の **友達の友達** ＋ **自分** |
| **全体** | **友達** の投稿 ＋ 公開設定が **公開** の **誰でも** ＋ **自分** |

## 6. 確認手順

### タスク A

1. プロフィール編集で公開範囲を変更して保存
2. DB で `default_visibility` を確認

### タスク B

1. シード投入後、各タブで T01〜T09 の表示を §3.3 と照合
2. 投稿が見えない場合はシードの再実行（画像パス切れの可能性あり）
